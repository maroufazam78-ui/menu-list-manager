# Local Tapas

Local Tapas is a simple menu management application built with HTML, CSS, and Vanilla JavaScript.

The application allows users to add menu items, mark them as selected, and automatically saves the data using the browser's Local Storage.

## Features

- Add new menu items
- Mark items as selected
- Automatically save data with Local Storage
- Event Delegation for efficient event handling
- Clean and responsive user interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API

## Concepts Practiced

- DOM Manipulation
- Event Delegation
- Local Storage
- Form Handling
- Array Methods
